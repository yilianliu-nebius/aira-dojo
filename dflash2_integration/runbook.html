Bounded DFlash2 research: first measured results

Decision: keep the integration running. The agent loop works end to end: the model proposes, the immutable evaluator trains and serves, and the measured throughput feeds the next proposal. No candidate beat the matched baseline yet. All numbers below are development screens, not verified wins.

This page reports the live state of the run described in the experiment proposal and the specdec agent research memo. The teacher is Qwen/Qwen3.8-27B, FP8, tensor parallel 1. The drafter is incoai/Qwen3.8-27B-DFlash2. The fitness metric is useful_output_tokens_per_second from stock SGLang serving, not a training loss.

1. The feedback loop is closed

The controller uses the upstream AIRA-dojo Greedy policy unmodified: operators, search policy, memory, journal, and checkpoints are native. The task adapter restricts the proposal space to a literal Python assignment of bounded parameters. The evaluator is immutable: it owns training, serving, validity, and fitness. This is the closed agent loop the memo asked for, at L4 scale.

Proof the loop uses evidence: the third recipe proposal cites the measured pooled diagnostics of the second trial. It observed that selector_teacher_agreement fell from 0.4732 to 0.4643 and selector_greedy_accepted_length fell from 4.0 to 3.75, then proposed a smaller learning rate to preserve early-prefix teacher compatibility. The agent read the measured result and changed its next proposal accordingly.

Each trial trains 32 updates on the shared feature cache, exports, serves on one H200, and benchmarks 32 requests. Positive deltas are wins; every measured delta is negative so far.

4. Integrity controls that held

  • The evaluator is immutable; fitness comes only from its stdout. The model cannot edit the verifier, teacher settings, or harness.
  • Both lanes share one absolute wall deadline; the architecture lane is capped at 1 trial and the recipe lane at 4, per the original ceiling.
  • Rank 512 stays excluded: its 6.67% parameter growth violates the 5% gate over the 1,924,404,480-parameter drafter.
  • Initialization parity is verified per trial: logit_max_error 0.0 and probability_max_error 0.0 before training.
  • Training prefixes are disjoint across trials; the feature cache manifest is hash-pinned (c62c7a8f…).
  • The controller refuses to overwrite a work directory, so each lane keeps its own journal and checkpoint.

5. How to read these numbers

These are not wins. Every measured candidate is below the matched baseline. The best journal candidate is a shortlist entry, not a verified improvement. Confirmation would need release and matched controls, isolated same-GPU A/B runs, randomized paired confidence intervals, and three seeds — outside this bounded screen.

The negative results still carry information. The memo's proxy-fidelity warning applies directly: a training-side selector improvement did not transfer to served throughput, and the pooled diagnostics explained why after the fact. A short-budget screen that rejects three candidates cheaply has done its job.
