Metric names need care

The table reports all valid generated output tokens divided by benchmark wall time. This includes capped responses. It does not count speculative candidate tokens.

The evaluator stores this fitness in top-level useful_output_tokens_per_second; its source is benchmark.tokens_per_second. The nested benchmark.useful_output_tokens_per_second has a different meaning: it counts only output from requests that reach natural EOS.

For Architecture 1, these rates are 312.59 total output tokens/s and 112.46 EOS-only tokens/s. The table shows EOS and cap counts to expose this distinction. No scorer or running search was changed to rename the fields.

Pooled acceptance is 1 + sum(accepted_tokens) / sum(verification_rounds). It is not the mean of per-request acceptance lengths.

2. Existing framework, not a custom search policy

4. Native released-weight training

The trainer uses SpecForge at fdcc2ed. It loads the released native DFlash2DraftModel strictly and uses native OnlineDFlashModel.

  • Objective: native hard-token DFlash CE plus strict natural-topK selector CE.
  • Selector: free released full-vocabulary codebooks; no inverse projection or reset to random codebooks.
  • Optimizer: AdamW; seed 42; eight anchors; block size eight.
  • Shared cache: eight train prefixes and two development prefixes, each limited to 512 tokens.
  • Train and development prefixes are disjoint. All candidates intentionally reuse the same frozen cache for a matched comparison.
  • Budget: 32 updates or 300 measured seconds, whichever comes first. Actual update time is about nine seconds; startup and export have separate timings.
  • All four valid candidates consumed 1,780 supervised tokens and passed strict saved-checkpoint reload.

The cache manifest has SHA256 c62c7a8f1bb613b641d18b515cd593a74b9521879885d4af45ccd0aa6bb89389. Native token labels and masks retain their next-token alignment.

The teacher head contract fixes the embedding, head, and final norm as BF16 tensors. Captured final hidden states precede the norm. The trainer applies GemmaRMSNorm once, with weight + 1 and epsilon 1e-6.

The released drafter has 1,924,404,480 parameters. Rank 384 adds 64,225,280 parameters, or 3.3374%, within the original 5% gate. Rank 512 exceeds that gate.

The rank-384 initialization probe measured zero maximum logit error and zero probability error on the first frozen development prefix. The native trainer also checks the new factor gradients.

Diagnostics pool counts as sum(numerator) / sum(denominator), not conversation means. Only declared numeric ratios and up to seven position bins reach the model. Raw cache arrays, token IDs, and hidden prompts do not.

Native teacher overlap uses full-vocabulary probabilities before top-p/top-k filters. It is not stock verifier acceptance probability. Two development conversations do not establish a general capacity bottleneck or its absence.
